Dry-run: registra o ajuste pelo mark na Hyperliquid, sem enviar ordens. O gatilho configurado para esta pool é usado exatamente como informado. Ao iniciar, o mark atual vira a âncora e nenhum ajuste real é realizado.

O método de saída escolhido define se a parcela fecha pelo prazo, pelo cruzamento ou também pela emergência de +0,40%. Se o preço reverter meia banda, o delta faltante é recomposto.
