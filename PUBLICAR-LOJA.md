# Publicar para instalação pelo navegador

Os arquivos da loja e a automação de imagem já estão prontos. Falta apenas um
repositório público no GitHub.

## Preparação única

1. Crie no GitHub um repositório público chamado `neutralis-umbrel`.
2. Envie todo o conteúdo desta pasta para a branch `main` do repositório.
3. Abra a aba **Actions** no GitHub e aguarde `Publicar imagem Neutralis`.
4. Na aba **Packages**, confirme que `neutralis-umbrel` está público.

Nenhuma chave privada ou configuração da sua conta é enviada ao GitHub. A
imagem contém apenas o monitor dry-run genérico.

## Instalação no Umbrel

Após a imagem estar pública:

1. Abra **App Store** no painel do Umbrel.
2. Abra o menu e entre em **Community App Stores**.
3. Adicione `https://github.com/RHstuff01/neutralis-umbrel`.
4. Abra **Neutralis Hedge** e clique em **Install**.
5. Clique em **Open** e escolha sua LP.

Os nomes dos menus podem mudar levemente entre versões do umbrelOS.
